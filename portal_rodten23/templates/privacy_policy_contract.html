Política de Privacidade

Última atualização: Setembro de 2026

Esta Política de Privacidade descreve como os dados são tratados na aplicação demonstrativa de integração com a API da Clicksign disponível no portfólio profissional de Rodrigo Alves Tenório ("Desenvolvedor"), em estrita conformidade com a Lei Geral de Proteção de Dados (LGPD - Lei nº 13.709/2018).

1. Princípio da Minimização e Não-Retenção de Dados

1.1. Alinhado ao princípio da minimização de dados da LGPD, esta Aplicação foi projetada para não armazenar nenhuma informação inserida no formulário de testes em banco de dados local ou servidores próprios do Desenvolvedor.
1.2. O Desenvolvedor não coleta, não cria perfis (profiling), não comercializa e não compartilha dados pessoais com fins lucrativos ou de marketing.

2. Dados Coletados e Finalidade Específica

2.1. A Aplicação coleta temporariamente em memória os seguintes dados informados pelo usuário:

  • Endereço de E-mail: Utilizado com a finalidade exclusiva de viabilizar o disparo técnico do Token OTP (One-Time Password) pela API de Sandbox da Clicksign, permitindo a conclusão da experiência prática de assinatura.
  • Nome, CPF e Nome de Empresa Fictícios: Tratados de forma efêmera apenas para compor as variáveis textuais transmitidas via API e renderizadas na tela do documento de simulação.

2.2. O usuário é advertido a preencher os campos com dados fictícios. Conforme definido nos Termos de Serviço, dados numéricos específicos exibidos ou gerados pela aplicação — como o CPF 868.872.680-94 — possuem caráter puramente ilustrativo/computacional, não correspondendo a tratamento de dados de pessoa natural identificada ou identificável por parte deste site.

3. Compartilhamento com Operadores de Dados (Clicksign)

3.1. Ao clicar em "Criar Contrato Teste", os dados inseridos são transmitidos diretamente para o ambiente de testes (Sandbox) da plataforma Clicksign (Clicksign Gestão de Documentos S.A., inscrita no CNPJ/MF sob o nº 12.499.520/0001-70), que atua como fornecedora da tecnologia de assinatura digital.
3.2. O processing dessas informações pela Clicksign segue as diretrizes, termos e políticas de privacidade da própria plataforma parceira (disponíveis em seus canais oficiais e documentação de desenvolvedores).

4. Segurança da Informação

4.1. Embora os dados não sejam guardados em base local, o tráfego de dados entre o navegador do usuário e as APIs integradas é protegido por criptografia de transporte (HTTPS).
4.2. Por se tratar de um ambiente puramente demonstrativo e público de portfólio, o usuário reconhece os riscos intrínsecos de tráfego na internet e é incentivado a utilizar apenas dados genéricos/fictícios no formulário.

5. Direitos do Titular dos Dados

5.1. Uma vez que esta aplicação não retém ou armazena dados em caráter permanente, o Desenvolvedor não possui histórico de dados a ser extraído, corrigido, portado ou excluído a pedido do usuário após o encerramento da sessão de navegação.

6. Contato

6.1. Para qualquer esclarecimento sobre a natureza técnica desta aplicação, o usuário poderá entrar em contato através dos canais profissionais disponibilizados na página principal deste portfólio.
